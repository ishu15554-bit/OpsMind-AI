
# Password Reset Troubleshooting

## Problem
User is unable to reset their account password or cannot log in.

## Possible Causes
- Incorrect username or email address.
- Expired password reset link.
- Password reset email not received.
- Account temporarily locked.
- Password policy requirements not satisfied.

## Troubleshooting Steps
1. Verify that the user has entered the correct username or email address.
2. Ask the user to request a new password reset link.
3. Check the email inbox and spam folder.
4. Verify that the reset link has not expired.
5. Check whether the account is temporarily locked.
6. Ensure the new password follows the organization's password policy.

## Resolution
Use a valid password reset link and follow the organization's approved password reset process.

## Escalation
Escalate unresolved password reset issues to the IT Help Desk or Identity and Access Management team.

## Safety
Never ask users to share their passwords.
Never store passwords in plain text.
Never share password reset links with unauthorized users.
