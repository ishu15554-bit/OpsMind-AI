
# Network Connectivity Troubleshooting

## Problem
User is unable to connect to the organization's network.

## Possible Causes
- Network cable disconnected.
- Wi-Fi connectivity issue.
- Incorrect IP configuration.
- DNS resolution failure.
- Network service outage.

## Troubleshooting Steps
1. Check whether the device is connected to the correct network.
2. Verify the device's IP configuration.
3. Test connectivity to the default gateway.
4. Check DNS resolution.
5. Review network monitoring alerts for outages.

## Resolution
Restore the correct network configuration or escalate the outage to the Network Operations team.

## Escalation
Escalate persistent connectivity failures to the Network Operations team.
