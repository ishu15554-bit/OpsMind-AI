
# Email Service Troubleshooting

## Problem
User is unable to send or receive emails.

## Possible Causes
- Mail server unavailable.
- Incorrect email configuration.
- Mailbox storage limit exceeded.
- Network connectivity issue.
- Authentication failure.

## Troubleshooting Steps
1. Verify the user's network connectivity.
2. Check the mail service availability.
3. Verify email account configuration.
4. Check mailbox storage usage.
5. Review mail server logs for errors.

## Resolution
Correct the configuration or restore the affected mail service after identifying the root cause.

## Escalation
Escalate unresolved issues to the Email Administration team.

## Safety
Do not request user passwords or expose confidential email content.
